{{- /* clip — embed a muted demonstration clip with a poster image and a graceful fallback. Used by the landing-page feature showcase. The inline clip autoplays ONCE and rests on its final frame (no loop, no controls). It is a button: activating it opens the same sources in an overlay at up to their native 1280px width, big enough to actually read, continuing from wherever the inline clip had got to. The overlay carries no controls either — a native control bar would grey out the bottom of the frame, where these clips put their critical content, and its download / playback-rate / PiP / volume affordances are all irrelevant. It plays on and stops. Overlay behaviour lives in assets/js/clip.js, loaded only on pages that use this shortcode — the shortcode sets the "hasClip" page-store flag and layouts/_partials/custom/head-end.html reads it. This mirrors how Hextra itself gates KaTeX behind "hasMath". Params: src (string, required) basename under /media, WITHOUT extension. Resolves /media/.webm and /media/.mp4. poster (string) poster image path under /media; defaults to the shared placeholder poster. caption (string) optional caption shown under the clip. alt (string) text shown when the clip cannot load / for a11y. Media conventions live in static/media/README.md. No real media is committed in the skeleton — these slots are placeholders. @example {{< clip src="feature-chat" caption="Chat over the agentic loop." >}} */ -}} {{- $src := .Get "src" -}} {{- $poster := .Get "poster" | default "placeholder-poster.svg" -}} {{- $caption := .Get "caption" -}} {{- $alt := .Get "alt" | default "Demonstration clip — coming soon." -}} {{- $webm := printf "/media/%s.webm" $src | relURL -}} {{- $mp4 := printf "/media/%s.mp4" $src | relURL -}} {{- $posterURL := printf "/media/%s" $poster | relURL -}} {{- .Page.Store.Set "hasClip" true -}}
