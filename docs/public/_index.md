# Documentation

> **[PLACEHOLDER — seeded stub. The real source is Joe's `docs/public` tree.]**

This documentation tree is **generated at build time** by `scripts/sync-docs.sh` from Joe's
`docs/public` tree, and is not committed to the site repository. Until Joe is a public repository,
the sync reads a **locally-seeded copy** of `docs/public` (these labeled placeholder stubs) so the
build is green and the sidebar renders. The single documented flip is to source `docs/public` from
a checkout of Joe's public repository (see the site README and the source switch in
`scripts/sync-docs.sh`).
